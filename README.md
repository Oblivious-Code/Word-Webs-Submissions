# Word-Webs-Submissions

A lightweight dictionary website built with plain HTML, CSS, and JavaScript.

Features:
- Search for any English word
- View definition, synonyms, antonyms, suffix, origin, and example usage
- Quick-word buttons for rapid browsing
- Works with the public Dictionary API and includes fallback word data

How to run locally:
Open Up https://oblivious-code.github.io/Word-Webs-Submissions/

Files included:
- index.html
- styles.css
- app.js
